NEXUS 2050
موقع تفاعلي عن التغيرات المناخية والتكنولوجيا

==================================================

نبذة عن المشروع
==================================================

NEXUS 2050 هو موقع تفاعلي يهدف إلى توعية الزائر بالتغيرات
المناخية وتأثيرها على كوكب الأرض، مع توضيح دور التكنولوجيا
والابتكار في مواجهة التحديات المناخية وبناء مستقبل أكثر استدامة.

تم تصميم الموقع بطريقة تفاعلية تجمع بين المعلومات العلمية
والتصميم العصري والحركات البصرية، بهدف جعل تجربة المستخدم
ممتعة وسهلة وفي الوقت نفسه تعليمية.

==================================================
2. مكونات المشروع

يتكون المشروع من الملفات الأساسية التالية:

index.html
يحتوي على هيكل ومحتوى صفحات الموقع.

style.css
يحتوي على التصميم والألوان والتنسيقات والحركات البصرية.

script.js
يحتوي على الوظائف التفاعلية والحركات والتفاعل مع المستخدم.

README.txt
يحتوي على شرح المشروع وطريقة تشغيله والبرامج واللغات
المستخدمة في تنفيذه.

==================================================
3. لغات وتقنيات البرمجة المستخدمة

HTML5
تم استخدام HTML5 لإنشاء هيكل الموقع وتنظيم محتواه.

CSS3
تم استخدام CSS3 لتصميم واجهة الموقع وإضافة الألوان
والتأثيرات والحركات والتنسيقات المتجاوبة مع أحجام الشاشات
المختلفة.

JavaScript
تم استخدام JavaScript لإضافة التفاعل والحركات الديناميكية
والتحكم في بعض عناصر الموقع.

==================================================
4. البرامج المستخدمة

Visual Studio Code
تم استخدامه لكتابة وتعديل أكواد المشروع.

Web Browser
تم استخدام متصفح الإنترنت لتشغيل الموقع ومعاينة النتيجة،
مثل Google Chrome أو Microsoft Edge.

==================================================
5. طريقة تحميل وتشغيل المشروع

أولًا:
يتم تحميل مجلد المشروع كاملًا على جهاز الكمبيوتر.

ثانيًا:
يتم فتح مجلد المشروع باستخدام Visual Studio Code.

ثالثًا:
يجب التأكد من وجود الملفات التالية داخل مجلد المشروع:

index.html
style.css
script.js
README.txt

رابعًا:
يتم فتح ملف index.html باستخدام متصفح الإنترنت.

يمكن أيضًا استخدام إضافة Live Server في Visual Studio Code
لتشغيل الموقع محليًا والحصول على تجربة أفضل أثناء التطوير.

==================================================
6. طريقة استخدام الموقع

يمكن للزائر التنقل بين أقسام الموقع من خلال شريط التنقل.

يستطيع الزائر استكشاف المعلومات المتعلقة بالتغيرات المناخية
والتعرف على بعض الحلول والتقنيات التي يمكن استخدامها
للمساعدة في بناء مستقبل مستدام.

تم تصميم بعض العناصر لتتفاعل مع حركة المستخدم والتمرير
والضغط، مما يجعل الموقع تجربة تفاعلية وليست مجرد صفحة
معلوماتية ثابتة.

==================================================
7. هدف المشروع

يهدف المشروع إلى الربط بين التغيرات المناخية والتكنولوجيا،
وتوضيح أن التكنولوجيا يمكن أن تكون أحد الأدوات المهمة في
فهم التغيرات المناخية وتقليل آثارها ودعم الحلول المستدامة.

كما يهدف المشروع إلى تقديم المعلومات بطريقة حديثة وتفاعلية
تناسب الجيل الجديد وتشجع على الاهتمام بالبيئة والمستقبل.

==================================================
8. ملاحظات

يفضل تشغيل المشروع باستخدام متصفح حديث مثل Google Chrome
أو Microsoft Edge للحصول على أفضل تجربة.

في حالة استخدام Live Server يمكن تشغيل الملف index.html
مباشرة من خلال Visual Studio Code.

==================================================
